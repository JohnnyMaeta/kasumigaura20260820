手順は、4つだけ

  1. 新しいスプレッドシートを開く — ブラウザのアドレスバーに sheet.new と打つと1手で開きます。
  2. 拡張機能 → Apps Script を開く。
  3. 最初から入っているコードを全部消して、下のコードを丸ごと貼る。
  4. 上の関数名が main になっているのを確かめて、▶実行 を押す。
初回だけ、承認画面が出ます。「このアプリは Google で確認されていません」と表示されたら——「詳細」→「（プロジェクト名）に移動」→「許可」の順に進んでください。これはあなた自身が作ったプログラムに、あなた自身が許可を出す画面です。

実行が終わると「週予定」シートができて、練習用カレンダーの来週の予定が並びます。カレンダーが変わったら、もう一度▶実行するだけです。

コード（コピーして貼るだけ）

練習用カレンダーのIDは、貼り付け済みです。あなたが書き換える場所はありません。

週予定書き出し.gs
/**
 * 週予定書き出し —— おみやげワーク版
 *
 * 練習用の公開カレンダーから来週1週間分の予定を読み取って、
 * 「週予定」シートに書き出します。カレンダーが変わったら、もう一度実行するだけ。
 *
 * 【置き場所】新しいスプレッドシート → 拡張機能 → Apps Script に貼ります。
 * 【実行するもの】▶実行を押すのは main です。
 */

// ▼ 練習用カレンダー（貼り替え不要。自分の学校で使うときだけ、ここを差し替えます）
const CALENDAR_ID = 'c_7ea8a4f2b303f1ce6b9e5daa7fd4d072aa1db87983e46f2f62676ff58b5924ce@group.calendar.google.com';
const SHEET_NAME = '週予定';      // ▼ 書き出す先のシート名
// -------------------------------------------------------------------------

const HEADER = ['日付', '曜日', '開始時刻', '予定名'];

/** これが本体です。▶実行を押すのはこの関数。 */
function main() {
  let calendar = CalendarApp.getCalendarById(CALENDAR_ID);

  // 練習用カレンダーをまだ追加していない場合は、ここで自動的に追加します
  if (!calendar) {
    try {
      calendar = CalendarApp.subscribeToCalendar(CALENDAR_ID);
    } catch (e) {
      throw new Error(
        '練習用カレンダーを追加できませんでした。\n' +
        'ワークのページにある「練習用カレンダーを追加」のリンクを押してから、もう一度▶実行してください。'
      );
    }
  }

  const week = nextWeek_();
  const events = calendar.getEvents(week.start, week.end);

  const rows = events.map(function (event) {
    const startedAt = event.getStartTime();
    return [
      ymd_(startedAt),
      weekdayOf_(startedAt),
      event.isAllDayEvent() ? '終日' : Utilities.formatDate(startedAt, 'Asia/Tokyo', 'H:mm'),
      event.getTitle()
    ];
  });

  const sheet = getOrCreateSheet_();
  if (sheet.getLastRow() > 1) {
    sheet.getRange(2, 1, sheet.getLastRow() - 1, HEADER.length).clearContent();
  }

  if (rows.length === 0) {
    // 静かな成功：仕組みは動いていて、来週の予定がないだけ
    SpreadsheetApp.getActive().toast(
      week.label + ' の予定は0件でした。時間をおいて、もう一度実行してみてください。',
      '書き出しました', 10
    );
    return;
  }

  sheet.getRange(2, 1, rows.length, HEADER.length).setValues(rows);
  sheet.getRange(2, 1, rows.length, 1).setNumberFormat('@');
  SpreadsheetApp.getActive().toast(week.label + ' の予定を ' + rows.length + ' 件、書き出しました。', '完了', 6);
}

// ===== ここから下は、読まなくても大丈夫な部分です =========================

/** 「週予定」シートを、なければ見出しつきで作ります。 */
function getOrCreateSheet_() {
  const ss = SpreadsheetApp.getActive();
  ss.setSpreadsheetTimeZone('Asia/Tokyo'); // 日付がずれないように、先に日本時間にそろえます

  let sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) sheet = ss.insertSheet(SHEET_NAME, 0);

  const header = sheet.getRange(1, 1, 1, HEADER.length);
  if (String(header.getValues()[0][0]) !== HEADER[0]) {
    header.setValues([HEADER]).setFontWeight('bold').setBackground('#e8eaed');
    sheet.setFrozenRows(1);
    sheet.setColumnWidth(1, 110);
    sheet.setColumnWidth(2, 50);
    sheet.setColumnWidth(3, 90);
    sheet.setColumnWidth(4, 380);
  }
  return sheet;
}

/**
 * 来週の月曜0時から、土曜0時までを返します。
 * スクリプトのタイムゾーン設定に左右されないよう、日本時間で組み立てています。
 */
function nextWeek_() {
  const today = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy-MM-dd').split('-').map(Number);
  const anchor = Date.UTC(today[0], today[1] - 1, today[2]);
  const day = new Date(anchor).getUTCDay();           // 0=日 … 6=土
  const untilMonday = ((8 - day) % 7) || 7;           // 次の月曜まであと何日か
  const monday = anchor + untilMonday * 24 * 60 * 60 * 1000;

  const start = new Date(monday - 9 * 60 * 60 * 1000);          // 日本時間の月曜0:00
  const end = new Date(start.getTime() + 5 * 24 * 60 * 60 * 1000); // 日本時間の土曜0:00

  return {
    start: start,
    end: end,
    label: Utilities.formatDate(start, 'Asia/Tokyo', 'M月d日') + 'の週'
  };
}

/** 2026-08-17 の形の文字列にします。 */
function ymd_(date) {
  return Utilities.formatDate(date, 'Asia/Tokyo', 'yyyy-MM-dd');
}

/** 日本時間での曜日を1文字で返します。 */
function weekdayOf_(date) {
  const n = ymd_(date).split('-').map(Number);
  const anchor = new Date(Date.UTC(n[0], n[1] - 1, n[2]));
  return ['日', '月', '火', '水', '木', '金', '土'][anchor.getUTCDay()];
}

ワーク②　学校評価アンケートを、方針と突き合わせる

実践②でお話しした「作文させるのではなく、突合と転記をやらせる」の練習です。人間がいちばん間違えやすい仕事を、AIに渡します。

練習用に、架空の学校の資料を3つ用意しました。どれも「📋 本文をコピー」のボタンがついています。

  1. 資料①　令和8年度 学校経営方針（校長が今年度いちばん力を入れたいこと）
  2. 資料②　令和8年度 教育課程の届出書（教育委員会に出した、実際の様式のもの。各教科・道徳・外国語活動・総合・特別活動の指導の方針）
  3. 資料③　令和7年度 学校評価アンケート項目（見直さずに、そのまま引き継ぐつもりだったもの）

この学校は今年度から方針が大きく変わりました。ところが、アンケートは去年のままです。この2つを人間の目で突き合わせるのが、毎年しんどい仕事でした。

  1. Gemini Notebookを開いて、新しいノートブックを作る（リンクは別タブで開きます）。
  2. ソースを追加 →「コピーしたテキスト」で、資料①②③を1つずつ貼る（3ソースになります）。
  3. 下のプロンプトを貼って、実行する。
Gemini Notebook に貼るプロンプト 
あなたは小学校の教務主任です。
アップロードした3つの資料（①学校経営方針 ②教育課程届出書 ③昨年度の学校評価アンケート項目）
を突き合わせて、今年度のアンケートをどう直すべきか整理してください。

次の3つを、それぞれ表で出してください。

【表1】昨年度の項目の判定
列は「昨年度の項目 / 判定（残す・直す・消す） / 理由 / 今年度の文案」。
理由には、方針や届出書のどこに書かれているかを必ず添えてください。

【表2】測れていない重点
今年度の重点目標や数値目標のうち、昨年度の項目では測れていないものを挙げ、
新しく足すべき項目の文案を書いてください。

【表3】そのほかの問題
意味が重複している項目、聞き方があいまいな項目、
小学校の実態に合っていない項目を指摘してください。

最後に、今年度のアンケート項目の完成版を、保護者用と児童用に分けて番号つきで出してください。
質問文は4件法（そう思う〜そう思わない）で答えられる形にそろえてください。
出てきた項目をそのまま採用しないでください。判断するのは人間です。AIにやらせているのは、方針とアンケートを1行ずつ照らし合わせる作業だけです。ここは人間がやると必ず見落とします。

仕上げに、完成した項目をGoogleフォームにする作業もAIに頼めます。「この項目でGoogleフォームを作るGASのコードを書いて」と続ければ、ワーク①と同じ手順（Apps Scriptに貼って▶実行）でフォームができます。手で1問ずつ入力すると、必ずどこかで写し間違えます。
